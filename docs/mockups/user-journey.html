Was ist neu

  • Website statt App: Spengler-Cup-Header oben, Cards-Navigation darunter. Auf dem Handy wird die Navigation zur wischbaren Leiste, kein App-Tabbar.
  • Spielerprofil statt einer Seite pro Karte: Basisinfos + alle Karten des Spielers, gesperrte mit Hinweis, wie man sie bekommt.
  • Karten-Detail als Modal (Desktop) bzw. Bottom-Sheet (Handy), mit Blättern durch die Karten des Spielers. KPIs stehen dort („Rückseite“), nicht auf der Karte.
  • Filter: Desktop mit Seitenleiste (Teams mit Logo, Kartentyp, Sortierung), Handy mit Chips + Filter-Sheet. Keine Dropdowns.
